# Gold Evaluation Files

This folder contains manually checked gold-standard TSV files for development
and held-out evaluation.

## Files

| File | Use | Sentence range |
|---|---|---|
| `sr-elexis-WSD_0001_0120-gold.tsv` | Development gold set | 1-120 |
| `sr-elexis-WSD_0301-0400-gold.tsv` | Held-out test gold set | 301-400 |
| `sr-elexis-WSD_0401-0500-gold.tsv` | Held-out test gold set | 401-500 |
| `sr-elexis-WSD_0501-0600-gold.tsv` | Held-out test gold set | 501-600 |

The three held-out files came from
`gold-files-20260511T150250Z-3-001.zip`. Together they provide 300 test
sentences. The `0001-0120` file is kept separate as the development set.
