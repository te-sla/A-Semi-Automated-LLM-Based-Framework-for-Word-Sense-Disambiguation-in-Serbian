# Llama_sense.ipynb

Notebook for running and analyzing sense assignment using the Llama LLM pipeline. Typical workflow includes:
- Loading Llama model outputs and sense-annotated data
- Processing and cleaning sense assignments
- Visualizing sense distributions and model performance
- Comparing results with other models or gold standards

**Usage:**
Use this notebook to evaluate and explore the performance of Llama on sense annotation tasks.
